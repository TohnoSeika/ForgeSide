  日期: 2026-06-02

■ 软件定位

  一个轻量级桌面工具，丢进 Forge NEO 所在文件夹即可使用。
  不需要安装，双击 exe 直接运行。
  自动识别 Forge NEO 的路径和配置。

■ 界面结构 — 四个 Tab

  UI 原型文件: ForgeNEO管理工具_UI原型.html（v3）
  双击浏览器打开即可预览完整界面效果。

  ── 全局元素 ──

  标题栏:
  · 左侧: 星形 Logo + 软件名 "Forge NEO 管理工具"
  · 右侧: NEO 识别状态 tag + 最小化按钮 + 关闭按钮
  · 难度: ★☆☆☆☆

  Tab 栏:
  · 四个药丸式 Tab 按钮: 快捷管理 / 图片参数 / 控制台 / 设置
  · Tab 栏最右侧: 全局状态指示器（绿点呼吸动画「运行中」/ 灰点「未启动」）
  · 状态指示器在所有 Tab 下均可见，切 Tab 不丢失运行状态感知
  · 难度: ★☆☆☆☆

  ── Tab 1: 快捷管理 ──

  上半部分 — 背景图片区域:
  · 一个圆角矩形区域，占据 Tab 上半部分
  · 默认显示虚线边框 + 占位提示，在「设置」中选择图片后可替换
  · 可加载用户自定义的背景图（如喜欢的作品、参考图等）
  · 难度: ★☆☆☆☆

  下半部分 — 5 列等宽卡片网格:
  · 4 个文件夹快捷入口: 输出目录 / 模型 / Lora / Embeddings
  · 第 5 格: 启动 Forge NEO 按钮，与文件夹卡片等宽等高
  · 文件夹卡片: 白底 / 暗底，hover 浮起，点击缩放反馈
  · 启动卡片: 粉底白字渐变，hover 阴影加深
  · NEO 运行中时启动卡片变灰，卡片副标题同步显示当前启动模式
  · 难度: ★☆☆☆☆

  ── Tab 2: 图片参数读取 ──

  功能:
  · 拖拽或浏览图片，读取 AI 生成参数
  · 只展示关键参数，不展示完整工作流

  各软件存储格式:

  WebUI / Forge
  ─ PNG tEXt chunk → key: "parameters"
  ─ 格式: 第一行正向 prompt → Negative prompt: 行 → 逗号分隔的 key: value 参数
  ─ 可解析出: prompt、负面 prompt、seed、steps、CFG、sampler、model、hires 参数等

  ComfyUI
  ─ PNG tEXt chunk → key: "prompt"（完整工作流 JSON）
  ─ 需要遍历 JSON 节点，识别关键节点类型提取参数
  ─ KSampler → seed, steps, cfg, sampler_name
  ─ CLIPTextEncode → 正负 prompt
  ─ CheckpointLoaderSimple → 模型名
  ─ EmptyLatentImage → 分辨率

  扩展参数处理策略:
  · 内置解析最常用扩展: ControlNet、ADetailer、FreeU、Tiled VAE 等
  · 其余扩展参数 → 原样展示在「原始数据」区域，不丢失信息
  · 难度: ★★☆☆☆

  ── Tab 3: 控制台 ──

  功能:
  · 显示 Forge NEO 的启动日志和运行状态
  · 纯展示，不需要在终端中输入任何内容
  · 全局状态指示器同步显示运行状态（绿点呼吸动画）
  · 终止按钮浮动于控制台右下角，粉色圆角 pill

  布局:
  · 命令行区域从上到下填满整个 Tab 空间
  · 默认开启自动滚动（无锁定按钮，始终保持最新日志可见）
  · 深色底 + 等宽字，不同日志级别不同颜色（info 蓝 / warn 黄 / error 红）
  · 每行前带灰色时间戳
  · 鼠标滚轮自由滚动查看历史日志

  技术实现:
  · 创建子进程启动 Forge NEO，捕获 stdout/stderr
  · 实时输出到带滚动的文本框
  · 自动滚动到底部
  · 可选: 解析 ANSI 颜色代码让日志更易读
  · 防重复启动机制
  · 终止时遍历并杀死完整进程树（.NET 8 原生支持）
  · 可配置启动参数（--listen、--port、--medvram 等）
  · 难度: ★★☆☆☆

  ── Tab 4: 设置 ──

  外观:
  · 亮色模式 / 暗色模式 二选一，卡片式选择
  · 亮色: 温暖柔和的日间色调（暖灰底 + 白卡片 + 粉色点缀）
  · 暗色: 深邃沉浸的夜间色调（深褐底 + 暗卡片 + 玫瑰粉点缀）
  · 主题选择自动保存（localStorage / 本地配置文件）
  · 难度: ★★☆☆☆

  启动模式:
  · SDP 模式 / Sage 模式 下拉选择
  · 切换后 Tab 1 启动卡片副标题同步显示当前模式
  · 技术实现: Process.Start 时选择对应的 bat 文件
  · 两个 bat 名称: 1.启动ForgeNeo(SDP).bat / 2.启动ForgeNeo(Sage).bat
  · 难度: ★☆☆☆☆

  代理服务器:
  · 开关控件 + URL 填写框（如 http://127.0.0.1:7897）
  · 开启后启动 NEO 时自动注入 HTTP_PROXY / HTTPS_PROXY / ALL_PROXY 环境变量
  · 额外设置 NO_PROXY=localhost,127.0.0.1
  · 若 NEO 已运行需重启生效（环境变量仅在进程创建时注入）
  · 难度: ★☆☆☆☆

  文件管理器:
  · 下拉选择默认文件管理器: 资源管理器 / XYplorer / Total Commander / Directory Opus / 自定义
  · 点击 Tab 1 文件夹卡片时，调用选定的管理器打开
  · 难度: ★☆☆☆☆

  背景图片:
  · 选择图片文件作为 Tab 1 背景区域的展示图
  · 选择 / 清除按钮 + 小预览窗
  · 难度: ★☆☆☆☆

■ UI 设计方向

  整体气质: 精巧小工具箱，温暖干净，不抢戏。创作者的工具，安静陪在旁边。
  配色: 暖灰底 + 白卡片 + 粉色 accent 点缀。不在大面积上使用粉色，保持分寸感。
  圆角: 10-22px，不是看不出来的 2px，是能感受到「柔软」的程度。
  阴影: 柔和分层，层次靠阴影表达，不用粗线分隔。
  字体: 轻盈无衬线体，字重 ≤500，留白慷慨。
  Tab: 圆角药丸式切换钮，选中态染粉色。
  开关: 自定义 toggle switch，滑到右边亮粉色。
  文件夹卡片: hover 浮起 + 轻按反馈，不是僵硬的 Button。
  控制台: 深色底 + 等宽字 + 彩色日志行 + 灰色时间戳。
  暗色模式: 完整深色主题，所有颜色经 CSS 变量统一控制。

■ 技术框架推荐

  ── 第一推荐: C# WinForms（.NET 8 自包含发布） ──

  文件大小: ~15-30MB，单个 exe
  启动速度: 毫秒级，极快
  内存占用: ~30MB，很轻
  无需安装: .NET 8 自包含发布，exe 自带运行时
  Win32 能力: 原生支持，调 XYplorer、杀进程树、读 PNG chunk 全部直接调用
  UI 美观度: 默认朴素，但可通过自定义绘制做出精致感

  ── 第二推荐: Go + Wails ──

  文件大小: ~10-15MB，最小
  启动速度: 快
  内存占用: 轻
  UI 美观度: 可用 HTML+CSS，能做得非常漂亮
  Win32 能力: 需要 Go 的系统调用，比 C# 绕一点

  ── 第三推荐: Python + PyInstaller ──

  文件大小: ~60-100MB（包解释器和依赖）
  启动速度: 慢（每次解包临时目录）
  内存占用: 偏高
  优势: 和 Forge NEO 同生态，路径识别方便

■ 可行性总结

  所有功能模块均有清晰、成熟的技术实现路径。
  无任何需要「攻克研究」的技术难点。
  整体难度适中，主要工作量在 UI 打磨和两个解析器（WebUI/ComfyUI PNG 参数解析）的编写上。
  代理注入、进程管理、bat 切换均为 C# 标准 API，一行或数行代码即可完成。
  暗色/亮色主题切换在 WinForms 中需自定义绘制实现，但逻辑简单（变量切换 + 控件重绘）。
