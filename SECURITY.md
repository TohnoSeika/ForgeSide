# Security Policy

## Supported versions

Only the latest release of ForgeSide receives security fixes.

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/TohnoSeika/ForgeSide/security/advisories/new).

Do not open a public issue for a security problem. Please include:

- A description of the issue and its impact
- Steps to reproduce
- The ForgeSide version and Windows version you tested

You will receive a reply as soon as the report has been reviewed. Once a fix is
ready, the issue will be disclosed with credit unless you prefer to stay anonymous.
